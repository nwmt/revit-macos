# Revit 2025

**Status: ✅ works.** Tested by hand on 2025.5: real work in a test project, exports and saving work. A few small
issues are left (below). Generative Design is turned off.

## What works / what doesn't

- ✅ Sign-in (through your Mac's browser), opening a project, walls, views, 3D, text, Materials, families, saving.
- ✅ Exports: PDF, DWG, DXF, DGN, DWF, IFC.
- ✅ Start screen, Manage Links and the web-based dock panels.
- ✅ Revit closes normally.
- ⚠️ The status bar at the very bottom of the window is sometimes blank (white) where it should show progress, for
  example during IFC export.
- ⚠️ "Do not show again" in Revit's dialogs is not remembered: the same question comes back on the next start.
- ❌ Generative Design: fails to load, so we turn it off.
- Not tested yet: add-ins (pyRevit, RevitLookup), the PDF printer, Dynamo, worksharing, the benchmark.

## Requirements

- Installer from your Autodesk Account: `Create_Installer_RVT_2025_…_WIN64.exe` in `installers/revit2025/`. The install
  downloads the base release (25.0.2.419, 11 GB) and the update (2025.5, 3.7 GB) from it
  ([installers/README.md](../installers/README.md)). Tested build: 25.5.0.57 (2025.5, on .NET 10).
- Extra files: `installers/redist/win7sp1/x64/msls31.dll`. Recommended: a current WebView2 runtime in
  `installers/redist/webview2/`. See [installers/README.md](../installers/README.md).
- `brew install sevenzip winetricks cabextract ghostscript python3`
- Disk: about 15 GB for the downloads, 12 GB for the unpacked files, about 7 GB for the bottle.

## Install

```bash
./install.sh 2025
```

This downloads Revit and its update (if needed), unpacks them, creates the bottle `rvt2025-a`, installs Revit
and all fixes, registers the sign-in link handler and puts Revit 2025 and Revit Viewer 2025 apps in `~/Applications`.

Defaults for new Revit users in the bottle: anti-aliasing off, and a dark or light theme (interface and view
background) to match your Mac's appearance at install time. To pick one: `REVIT_THEME=dark ./install.sh 2025`
(or `light`). Both can be changed later in Revit's Options.

## First launch

Revit opens the Autodesk sign-in page in your Mac's web browser. After you sign in, the browser asks which app should
open the link. Choose **Autodesk Sign-In (rvt2025-a)**.

## Workarounds

The install applies all of these. Step names match `scripts/install-odis.sh`. Mostly the same as
[2026](2026.md); what is specific to 2025 is marked.

| Step | What breaks | What we do |
|---|---|---|
| `rvt`, `pkgs` | Autodesk installer (ODIS) | Install the MSI and packages directly |
| `revitini` (2025) | "Cannot load the required component Autodesk RealDWG Shared", Revit closes on start. Revit looks RealDWG up through Autodesk's installer database, which we don't use | Tell Revit where RealDWG is in `Revit.ini` |
| `licensing`, `svcshim` | Licensing service does not start as a Windows service | Small wrapper service runs it |
| `ncryptshim` | Crash on start (signature check) | Own `ncrypt.dll` for Revit |
| `richedit`, `tlbpin` | Crash on text when creating a project | Microsoft RichEdit DLLs + type library cache |
| `warpshim` | Materials dialog does not open | Software D3D11 device → normal device |
| `d3d9dxvk` | Direct3D 9 panels unreliable | DXVK for Direct3D 9 |
| `webview2` | Built-in web pages fail (old browser runtime) | Install a current WebView2 runtime |
| `rvtfix` (2025) | Start screen and Manage Links blank (their browser is CefSharp, as in 2023) | Browser draws inside Revit's process |
| `wv2fix` | Browser in dock panels crashes on clicks and resizes | Own `version.dll` in the browser process |
| `gdoff` | Generative Design error on start | Turn the add-in off |
