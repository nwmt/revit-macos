# Revit 2021

**✅ Works** on 2021.1.2 (build 21.1.21.45), the version in the installer; the 2021.1.10 update is not applied.
Tested by hand after a fresh `./revit install 2021`.

## Works

- **Sign-in and files:** sign-in in Revit's own window, saving.
- **Modeling and views:** plans, 3D graphics, fonts, Materials.
- **Output:** printing to **Revit PDF**; the other exports.
- **Dynamo:** its window draws correctly.

## Known issues

- **The 2021.1.10 update is not installed.** CrossOver's installer engine cannot apply its Revit patch: it stops with
  an error. Revit stays at 2021.1.2.
- **Revit 2021 has no File → Export → PDF.** Print to the **Revit PDF** printer instead:
  `./revit addins 2021 --only pdfprinter` (needs Ghostscript).
- **Dynamo has no 3D background preview.** It is turned off on purpose.

## Not tested

Dynamo graphs, add-ins (RevitLookup, pyRevit), worksharing, long sessions.
