# Revit 2023

**✅ Works** on 2023.0 (build 20220304_1515). Tested by hand: the everyday basics work. A fresh
`./revit install 2023` was checked too.

## Works

- **Sign-in and files:** sign-in in Revit's own window, license, new project, saving. Revit closes cleanly.
- **Modeling and views:** walls, 3D, visual styles, shadows, anti-aliasing, Materials; web panels; the start screen
  (it may stay blank until you click inside the window).
- **Output:** PDF through File → Export → PDF and printing to **Revit PDF** (files go to `~/Documents/Revit-PDF`);
  export to DWG, DXF, DGN, DWF and IFC.
- **Dynamo and add-ins:** Dynamo 2.13 graphs run and results show in Revit views; pyRevit 7.0.0 and RevitLookup
  2023.5.4 load and their windows open.

## Known issues

- **With a project open, Home shows the last view's picture on top of the start screen.** The tiles underneath
  still respond to clicks.
- **Dynamo's node library on the left is empty.** It is an Internet Explorer page that Wine's browser engine does
  not run. Right-click the canvas to search for nodes.
- **Dynamo has no 3D background preview.** It is turned off on purpose.
- **IFC export hung once** (no progress, one CPU core busy) and worked the next three times. If it hangs:
  `./revit stop 2023`, then export again.
- **Black rectangles appear across Revit after add-ins load.** `./revit addins 2023` prevents this.
- **Generative Design is turned off.** It fails to load with an error on start.
