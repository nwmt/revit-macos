# Revit 2020

**✅ Works** on 2020.2 (build 20.2.12.1). Tested by hand on real tasks. A fresh `./revit install 2020` from the
7-part Autodesk download was checked too.

## Works

- **Sign-in and files:** sign-in and license, open, save and backups, linking DWG and RVT, copy and paste between
  Revit and macOS, Revit Viewer.
- **Modeling and views:** families, Load Family, modeling, text, dimensions, tags, Materials, Options; 3D views
  (including Ray Trace), sections, sheets, schedules.
- **Output:** export to DWG, DXF, DGN, DWF, FBX, IFC and images; printing to **Revit PDF**, portrait and landscape
  sheets.
- **Dynamo and add-ins:** Dynamo graphs run; RevitLookup 2020.0.0.3 and pyRevit 4.8.12.
- **Retina and Mac keys:** sharp text and drawings on a Retina screen, also with an external display; Cmd+Z, Cmd+S,
  Cmd+C and Cmd+V work as Ctrl, left Option opens the ribbon's KeyTips. `./revit set 2020 retina=off` or `keys=windows`
  turns them off.
- **Trackpad (menu bar app):** in Revit's views two fingers pan, Shift and two fingers orbit, a pinch zooms;
  schedules, Project Browser and Properties keep scrolling.
- **An AI assistant through the MCP server for Revit (Python):** `./revit mcp 2020 --server python`
  ([how](../docs/mcp.md#mcp-server-for-revit-python)). Tried from a fresh bottle: the model, levels, views and pictures
  of them, families, parameters, colors, Python in Revit, placing a family, Save As and opening a document, each change
  after Yes in Revit; five requests at once; Connect again while connected; `./revit stop` while connected.
- **Enscape 3.4.4:** the real-time view with materials and lighting, moving with the keys and the mouse, switching
  views, exporting images. `./revit addins` installs it only when you name it: with your own installer
  ([where it goes](../installers/README.md#add-ins-optional)), run
  `./revit addins 2020 --only enscape --accept-eula enscape`. It installs Enscape together with the fixes
  it needs.

## Known issues

- **Dynamo has no 3D background preview.** It is turned off on purpose.
- **Enscape brings Revit to the front** when you pick a view in Enscape whose model changed: Enscape reads the model
  from Revit again. Click into the Enscape window to go on.
- **Changing the quality in Enscape pauses it for 30–40 seconds.**
- **Enscape installed without the `enscape` step crashes Revit on Start.** See
  [Troubleshooting](../docs/troubleshooting.md#pressing-start-in-enscape-crashes-revit).
- **pyRevit 6.x does not load.** It needs a newer .NET Framework than Revit 2020 can run here. `./revit addins 2020`
  installs pyRevit 4.8.12.
- **The MCP server's `close_document` hangs Revit.** Close documents in Revit yourself; if it happened,
  `./revit stop 2020`.
- **pyRevit 4.8 forgets its settings** in bottles that got it before the `pyrevit` step gave it a user config:
  `./revit doctor 2020` warns, `./revit addins 2020 --only pyrevit` fixes it.

## Not tested

Crash recovery, upgrading files from older versions, long sessions, offline use, worksharing.
Enscape: video and panorama export, long sessions, large projects, Enscape 4.x.

## Notes

- Do not install .NET Framework 4.7.2 or 4.8 into this bottle: Revit 2020 crashes on them.
- Add your Mac's name to `/etc/hosts`, or Revit pauses for about 5 seconds again and again:
  [how](../docs/troubleshooting.md#revit-pauses-for-about-5-seconds). `./revit install` warns when it is missing.
