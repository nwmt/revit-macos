# Revit 2023

**Status: ⚠️ mostly works.** Tested by hand: the core modeling workflow works.
Generative Design is turned off.

## What works / what doesn't

- ✅ Sign-in (in Revit's own window) and license, new project, walls, 3D, visual styles, shadows, anti-aliasing,
  Materials, saving.
- ✅ Web-based dockable panels.
- ✅ Start screen. It may stay blank until you click inside the window.
- ⚠️ With a project open, **Home** shows the last view's picture on top of the start screen. The tiles underneath still
  respond to clicks.
- ✅ PDF: built-in export (File → Export → PDF) and printing to the **Revit PDF** printer (files go to `~/Documents/Revit-PDF`).
- ✅ Export to DWG, DXF, DGN, DWF and IFC. IFC export hung once (no progress, one CPU core busy) and passed the next three times.
- ✅ Dynamo 2.13: graphs run, results show in Revit views. Dynamo's own 3D background preview is off.
- ⚠️ Dynamo: the node library on the left is empty (it is an Internet Explorer page, and Wine's browser engine does not run
  its scripts). Right-click the canvas to search for nodes.
- ✅ Revit closes cleanly.
- ⚠️ The first launch after sign-in can hang on the splash screen. Quit Revit and start it again.
- ❌ Generative Design: turned off, as in 2026.
- Not tested yet: add-ins, worksharing, long sessions.

## Requirements

- Installer from your Autodesk Account, all 5 parts in `installers/revit2023/`:
  `Revit_2023_G1_Win_64bit_dlm_001_005.sfx.exe` … `_005_005.sfx.exe` (4 × 1.97 GB + 418 MB, about 8.3 GB).
  The install unpacks them on the Mac (about 12.5 GB); you do not run them. Tested build: 20220304_1515 (2023.0).
- Extra files: `installers/redist/dotNetFx40_Full_x86_x64.exe` and `installers/redist/win7sp1/x64/msls31.dll`.
  See [installers/README.md](../installers/README.md).
- `brew install sevenzip winetricks cabextract ghostscript python3`
- Disk: about 8.3 GB for the download, 12.5 GB for the unpacked files (you can delete them afterwards), about 12 GB for the bottle.

## Install

```bash
./install.sh 2023
```

This unpacks the installer, creates the bottle `rvt2023-a`, installs .NET Framework 4.8, Revit and all fixes, and puts
Revit 2023 and Revit Viewer 2023 apps in `~/Applications`. It takes about 15 minutes, most of it unpacking.

## First launch

Revit shows the Autodesk sign-in window. Sign in. If Revit then stays on the splash screen, quit it and start it again.

## Speed

RFO Benchmark 2023 (Full_Simplified, average of 3 runs, lower is better) on an Apple M5 Mac, 16 GB, CrossOver 26.3:

| | Mac (Apple M5, 16 GB) | Windows desktop (Intel i9-13900KS, RTX 4090) |
|---|---:|---:|
| Modeling | 115.6 s | 55.0 s |
| Graphics | 28.3 s | — |

The Windows numbers come from the reference report that ships with the benchmark: a top desktop CPU, and its graphics
test is a different set, so it is left out. Runs were steady (modeling 116.8 / 115.2 / 114.8 s).

## Workarounds

The install applies all of these. Step names match `scripts/install-odis.sh`. Revit 2023 uses the new Autodesk
installer, like 2026, but inside it is close to 2020: .NET Framework 4.8 and the AdSSO sign-in window.

| Step | What breaks | What we do |
|---|---|---|
| `rvt`, `pkgs` | Autodesk installer (ODIS) | Install the MSIs directly |
| `dotnet` | .NET Framework 4.8 installer refuses to run on "Windows 10" | Install real 4.0, then 4.8 as Windows 7 |
| `licensing`, `svcshim` | Licensing service does not start as a Windows service | Small wrapper service runs it |
| `adsso`, `ssoenv` | Sign-in window crashes on the GPU | Sign-in window runs without GPU |
| `wbemshim` | Crash on New Project and in Options | Own WMI wrapper |
| `ncryptshim` | Crash on start (signature check) | Own `ncrypt.dll` for Revit |
| `richedit`, `tlbpin` | Crash on text when creating a project | Microsoft RichEdit DLLs + type library cache |
| `warpshim` | Materials dialog does not open | Software D3D11 device → normal device |
| `d3d9dxvk` | Direct3D 9 panels unreliable | DXVK for Direct3D 9 |
| `gdoff` | Generative Design error on start | Turn the add-in off |
| `pdfprinter` | No printer, so Print and Page Setup do not open | **Revit PDF** printer: PostScript → Ghostscript → PDF |
| `dynamo` | Black squares and lag with Dynamo open | Dynamo without hardware acceleration and 3D background preview |
| `rvtfix` | Start screen blank (built-in browser draws from a separate process) | Browser draws inside Revit (`--in-process-gpu`) |

The fixes after `licensing` are carried over from Revit 2020 and 2026 as they are. We have not yet checked one by one
which of them 2023 still needs. The "What breaks" column describes what we saw in those versions.
