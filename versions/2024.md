# Revit 2024

**Status: ✅ works.** Tested by hand on 2024.3.6: real work in a test project, exports and saving work. A few small
issues are left (below). Generative Design is turned off.

## What works / what doesn't

- ✅ Sign-in (through your Mac's browser) and license.
- ✅ Start screen, with no black or blank areas.
- ✅ Opening a project, views, 3D, text, Materials, saving.
- ✅ Web-based dock panels.
- ✅ Exports: PDF, DWG, DXF, DGN, DWF, IFC.
- ✅ Dynamo 2.19: graphs run, the node library on the left is filled, results show in Revit views.
- ⚠️ Printing to the "Revit PDF" printer works (PDFs land in `~/Documents/Revit-PDF`), but the first print sometimes
  produces nothing: print again. Same as in 2025.
- ❌ Generative Design: turned off, as in 2023 and 2025.
- ✅ The RFO Benchmark runs to the end.
- ✅ Add-ins: pyRevit 7.0.0 and RevitLookup 2024.3.4 load and their windows open. The add-in script also trusts their
  publishers, so Revit doesn't ask "Always Load?" on every start.
- Not tested yet: worksharing, long sessions.

## Requirements

- Installer from your Autodesk Account: `Create_Installer_RVT_2024_…_WIN64.exe` in `installers/revit2024/`. The install
  downloads the base release from it (5 parts `Revit_2024_G1_Win_64bit_r2_dlm_00N_005.sfx.exe`, 11 GB, build 24.1.11.26)
  and the update (2024.3.6, 2.2 GB) ([installers/README.md](../installers/README.md)). If you already have the 5 parts,
  they are used as they are. Tested build: 24.3.60.12 (2024.3.6).
- Extra files: `installers/redist/dotNetFx40_Full_x86_x64.exe` and `installers/redist/win7sp1/x64/msls31.dll`.
  Recommended: a current WebView2 runtime in `installers/redist/webview2/`. See [installers/README.md](../installers/README.md).
- `brew install sevenzip winetricks cabextract ghostscript python3`
- Disk: about 13 GB for the downloads, 13 GB for the unpacked files (you can delete them afterwards), about 16 GB for the bottle.

## Install

```bash
./install.sh 2024
```

This unpacks the installer and lays the update over it, creates the bottle `rvt2024-a`, installs .NET Framework 4.8,
Revit 2024.3.6 and all fixes, registers the sign-in link handler and puts Revit 2024 and Revit Viewer 2024 apps in
`~/Applications`. It also installs Dynamo and a "Revit PDF" printer. It takes about 15 minutes after unpacking.

Defaults for new Revit users in the bottle: anti-aliasing off, and a dark or light theme (interface and view
background) to match your Mac's appearance at install time. To pick one: `REVIT_THEME=dark ./install.sh 2024`
(or `light`). Both can be changed later in Revit's Options.

Optional add-ins (RevitLookup 2024.3.4 + pyRevit 7.0.0, plus the `trust` and `wpfsw` fixes):

```bash
REVIT_YEAR=2024 ./scripts/d8-addins.sh rvt2024-a
```

## First launch

Revit opens the Autodesk sign-in page in your Mac's web browser. After you sign in, the browser asks which app should
open the link. Choose **Autodesk Sign-In (rvt2024-a)**.

## Speed

RFO Benchmark (Full_Simplified, on 2024.3.6, anti-aliasing off): modeling 122.9 s, graphics 29.9 s on an Apple M5 Mac;
the benchmark's Windows reference (Intel i9-13900KS, RTX 4090) is 60.2 s modeling. Details and caveats:
[docs/benchmarks.md](../docs/benchmarks.md).

## Workarounds

The install applies all of these. Step names match `scripts/install-odis.sh`. Revit 2024 sits between
[2023](2023.md) and [2025](2025.md): .NET Framework 4.8 and the Revit MSI as in 2023, sign-in, WebView2 and RealDWG as
in 2025. Most fixes are carried over as they are; we have not yet checked one by one which of them 2024 still needs.

| Step | What breaks | What we do |
|---|---|---|
| `rvt`, `pkgs` | Autodesk installer (ODIS) | Install the MSIs and packages directly |
| `rvt` (2024) | The update is a patch to Revit's MSI, not a new installer | Apply it while installing the MSI |
| `dotnet` | .NET Framework 4.8 installer refuses to run on "Windows 10" | Install real 4.0, then 4.8 as Windows 7 |
| `licensing`, `svcshim` | Licensing service does not start as a Windows service | Small wrapper service runs it |
| `revitini` | Revit looks RealDWG up through Autodesk's installer database, which we don't use | Tell Revit where RealDWG is in `Revit.ini` |
| `wbemshim` | Crash on New Project and in Options (seen in 2020 and 2023) | Own WMI wrapper |
| `ncryptshim` | Crash on start (signature check) | Own `ncrypt.dll` for Revit |
| `richedit`, `tlbpin` | Crash on text when creating a project | Microsoft RichEdit DLLs + type library cache |
| `warpshim` | Materials dialog does not open | Software D3D11 device → normal device |
| `d3d9dxvk` | Direct3D 9 panels unreliable | DXVK for Direct3D 9 |
| `webview2`, `wv2fix` | Built-in web pages fail (old browser runtime), browser crashes | Current WebView2 runtime, own `version.dll` in the browser |
| `rvtfix` | Start screen blank (its browser, CefSharp, draws from a separate process) | Browser draws inside Revit (`--in-process-gpu`) |
| `gdoff` | Generative Design error on start | Turn the add-in off |
| `pkgs` | Steel Connections installs its language files into a wrong "Revit 2024Revit 2024" folder | Move them into Revit's folder |
| `pdfprinter` | No printer, so Print and Page Setup don't open | "Revit PDF" printer → PDF via Ghostscript |
| `dynamo` | Dynamo's 3D preview draws black squares and lags (2020, 2023) | Dynamo without hardware acceleration and background preview |
| `trust` (add-ins) | Revit asks "Always Load?" for each add-in on every start | Trust the add-in publishers ahead |
| `wpfsw` (add-ins) | Black rectangles after add-ins load | WPF draws in software |
