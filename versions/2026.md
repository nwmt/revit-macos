# Revit 2026

**⚠️ Mostly works** on 2026.5 (build 26.5.0.55). Tested by hand: the core modeling works. Web panels sometimes
redraw.

## Works

- **Sign-in and files:** sign-in through your Mac's browser, new project, saving.
- **Modeling and views:** walls, modeling, text, 3D, Materials. The RFO Benchmark runs to the end.
- **Families:** Insert → Load Autodesk Family: loading into the project.
- **Add-ins:** pyRevit 7.0.0 and RevitLookup 2026.1.4 load and their windows open.

## Known issues

- **The start screen and Manage Links sometimes redraw.** Their browser process rarely crashes; it restarts by
  itself.
- **Black rectangles appear across Revit after add-ins load.** `./revit addins 2026` prevents this.
- **Generative Design is turned off.** It fails to load with an error on start.

## Not tested

Printing to PDF, exports, worksharing, long sessions.

## Notes

- `./revit install 2026` does not install Dynamo yet.
- Add-ins and the RFO Benchmark were tested on 2026.0 only. The base release alone (26.0.4.409) was tested too.
