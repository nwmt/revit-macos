# Revit 2024

**✅ Works** on 2024.3.6 (build 24.3.60.12). Tested by hand on real work in a test project.

## Works

- **Sign-in and files:** sign-in through your Mac's browser, license, opening a project, saving.
- **Modeling and views:** views, 3D, text, Materials; the start screen with no black or blank areas; web panels.
  The RFO Benchmark runs to the end.
- **Output:** export to PDF, DWG, DXF, DGN, DWF and IFC; printing to **Revit PDF** (files go to
  `~/Documents/Revit-PDF`).
- **Dynamo and add-ins:** Dynamo 2.19 graphs run, the node library is filled, results show in Revit views; pyRevit
  7.0.0 and RevitLookup 2024.3.4 load and their windows open. `./revit addins 2024` also trusts their publishers, so
  Revit does not ask **Always Load** on every start.

## Known issues

- **The first print to Revit PDF sometimes produces nothing.** Print again.
- **Dynamo has no 3D background preview.** It is turned off on purpose.
- **Generative Design is turned off.** It fails to load with an error on start.
