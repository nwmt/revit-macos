# Revit 2027

**✅ Works** on 2027.3 (build 27.3.0.28). Tested by hand: sign-in, saving, modeling, 3D, Materials, PDF, exports,
families from Autodesk's online library, Dynamo, RevitLookup, pyRevit and its agent, the Revit MCP Server, and the
menu bar app's trackpad gestures.

## Works

- **Sign-in and files:** sign-in through your Mac's browser, new project (Metric); project templates are found. Save,
  Save As and opening the file again; backup copies (`.0001.rvt`) appear. The sample projects on the start screen.
- **Modeling and views:** walls, modeling, 3D, text, Materials; the start screen (all tabs), Project Browser, web
  panels, Manage Links, Collaborate → Issues. No browser crashes seen in a session.
- **PDF and exports:** File → Export → PDF, DWG, DXF, DGN, DWF, IFC, images.
- **Families:** Insert → Load Autodesk Family: search and loading into the project.
- **Dynamo:** Dynamo 4.2: the node library and its search, graphs, a wall made by a graph, preview in Revit views, a
  new workspace.
- **Add-ins:** RevitLookup 2027.0.4 and pyRevit 7.0.0 load and their windows open. `./revit addins 2027` installs them.
- **Revit MCP Server (Write-Tools Technical Preview):** an AI assistant on the Mac reads the open model through
  `./revit mcp 2027`: the active view, a search of the model, an element's parameters. With `--write` it changed a
  parameter, and Autodesk's review of the session's changes listed it. Installed only when you name it, and it turns
  on Autodesk analytics in that bottle: [docs/mcp.md](../docs/mcp.md).
- **pyRevit's agent:** an AI assistant on the Mac connected through `./revit mcp 2027 --server pyrevit`: it read the
  model, captured a 3D view and changed a wall after approval in Revit. The same server built a small house: walls, a
  floor, a roof, a door and windows: [docs/mcp.md](../docs/mcp.md).
- **Trackpad (menu bar app):** in 3D, plan, section and sheet views two fingers pan, Shift and two fingers orbit, a
  pinch zooms. Schedules, Project Browser, Properties and the ribbon keep scrolling; the mouse wheel is unchanged.
  Pausing the gestures in the app, and moving the pointer off the window or to another screen mid-gesture, leave no
  button held.
- **Enscape 4.18 LTS:** signing in to Chaos through your Mac's browser, the real-time view, moving with the keys and the
  mouse, the menus, Asset Library in Enscape and in Revit. `./revit addins` installs it only when you name it: with your own
  installer ([where it goes](../installers/README.md#add-ins-optional)) and Revit closed, run
  `./revit addins 2027 --only enscape --accept-eula enscape`. It installs Enscape together with the fixes
  it needs.
- **Retina and Mac keys:** sharp text and drawings on a Retina screen, also with an external display. Cmd+Z, Cmd+S,
  Cmd+C and Cmd+V do what Ctrl does on Windows; left Option opens the ribbon's KeyTips; right Option types special
  characters. `./revit set` turns them off.
- **Light or dark like the Mac:** Revit starts in the Mac's look, and repaints itself, the view included, when the Mac
  turns light or dark while the menu bar app is open; also with Appearance set to Auto. `./revit set 2027 theme=dark`
  (or `light`) keeps one theme, `theme=mac` follows the Mac again. The status bar follows too.

## Known issues

- **Dynamo opens with a white window for a few seconds.** It closes by itself, then Dynamo's main window opens.
- **Dynamo has no 3D background preview.** It is turned off on purpose.
- **A large model opens and draws slowly the first time.** The Snowdon Towers sample takes about a minute to open and
  about a minute and a half to draw its first sheet; Revit does not respond meanwhile. Wait: it is not stuck.
- **Other web windows sometimes redraw when a new one opens.** Nothing is lost.
- **Generative Design is turned off.** Not checked separately on 2027.
- **Dragging the Enscape view sometimes goes wrong:** the view only tilts or keeps spinning, or the pointer stays stuck
  in the middle of the view. Seen a few times, not on demand. Press Cmd+Tab to get the pointer back.
- **An Enscape tooltip can stay on screen** after the pointer moves on.
- **After Retina is turned on or off, the first start may open Revit's window at another size.** Maximize it, quit
  Revit and start it again.
- **Views draw slower with Retina** ([how much](../docs/benchmarks.md#notes-per-version)). If speed matters more than
  sharpness: `./revit set 2027 retina=off`.
- **Windows dialogs stay light in the dark theme** (Open, Save As and others Wine draws). Revit's own panels follow the
  theme.
- **While a dialog is open, a theme change leaves the Project Browser empty.** It fills again once the dialog closes.
- **Revit quit while maximized on a second display starts maximized in the wrong place.** Click Restore, then
  Maximize.

## Not tested

Worksharing, File → Print. Appearance Auto turning light or dark by itself at sunrise or sunset. The MCP Server's Experimental-Tools variant with an AI assistant. Enscape: video and panorama export, long sessions, large projects, Enscape 4.21. Cmd+Q, Cmd+H and a Windows keyboard.
