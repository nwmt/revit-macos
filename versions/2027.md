# Revit 2027

**⚠️ Mostly works** on 2027.3 (build 27.3.0.28). Tested by hand: sign-in, a new project, modeling, 3D, text,
Materials. Many everyday features are not tested yet.

## Works

- **Sign-in and files:** sign-in through your Mac's browser, new project (Metric); project templates are found.
- **Modeling and views:** walls, modeling, 3D, text, Materials; the start screen (all tabs), Project Browser, web
  panels, Manage Links, Collaborate → Issues. No browser crashes seen in a session.

## Known issues

- **Other web windows sometimes redraw when a new one opens.** Nothing is lost.
- **Generative Design is turned off.** Not checked separately on 2027.

## Not tested

Saving, printing, add-ins, loading families from Autodesk's online library.

## Notes

- The installer ships only about 48 families.
- `./revit addins` is not set up for 2027 yet.
- The base release alone (27.0.4.412) was tested too.
