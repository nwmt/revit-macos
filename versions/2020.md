# Revit 2020

**Status: ✅ works.** Tested by hand on real tasks. Two known limits: PDF prints are always portrait, and Dynamo runs without its 3D background preview.

## What works / what doesn't

- ✅ Sign-in and license, open / save / backups, families, modeling, text, dimensions, tags.
- ✅ 3D views (including Ray Trace), sections, sheets, schedules, Load Family, Materials, Options.
- ✅ Clipboard between Revit and macOS, Cyrillic keyboard layout.
- ✅ Export to DWG, DXF, DGN, DWF, FBX, IFC and images. Link DWG and RVT.
- ✅ Add-ins: RevitLookup 2020.0.0.3, pyRevit 4.8.12.
- ⚠️ Print to PDF works, but the page is always portrait (landscape sheets come out rotated on a portrait page).
- ⚠️ Dynamo works, but without the 3D background preview.
- ❌ Enscape 3.4.4 / 4.0: pressing Start crashes Revit (needs Vulkan features the Mac does not have).
- ❌ pyRevit 6.x: needs a newer .NET Framework than Revit 2020 can run here.
- Not tested yet: crash recovery, upgrading files from older versions, long sessions, offline use, worksharing, Retina scaling.

## Requirements

- Installer: `installers/revit2020/Revit_2020_G1_Win_64bit_r3_dlm.exe` (self-extracting archive, about 12 GB).
- Extra files: `installers/redist/dotNetFx40_Full_x86_x64.exe` and `installers/redist/win7sp1/x64/msls31.dll`.
  See [installers/README.md](../installers/README.md).
- `brew install sevenzip winetricks cabextract ghostscript python3`
- Disk: about 10 GB for the installer, about 10 GB for the unpacked files, 20–30 GB for the installed bottle.
- Recommended: add your Mac's name to `/etc/hosts` (see [Troubleshooting](../docs/troubleshooting.md#revit-pauses-for-about-5-seconds)).
  The install script warns you if it is missing.

## Install

```bash
./install.sh 2020
```

This builds the compiler for our fixes, creates the bottle (Revit, .NET 4.7, VC++, all fixes; about 9 minutes)
and puts a Revit 2020 app in `~/Applications`.

Optional add-ins (RevitLookup + pyRevit 4.8.12):

```bash
REVIT_YEAR=2020 ./scripts/d8-addins.sh rvt2020-a
```

Do not install .NET Framework 4.7.2 or 4.8 into this bottle. Revit 2020 crashes on them.

## First launch

Sign in with your Autodesk account. If Revit then hangs on the splash screen, quit it and start it again.
After that, sign-in comes from the cache.

## Workarounds

The install applies all of these. Step names match `scripts/d6-install-revit.sh`.

| Step | What breaks | What we do |
|---|---|---|
| `licensing`, `svcshim` | Licensing service does not start as a Windows service | Small wrapper service runs it |
| `adsso`, `ssoenv` | Sign-in window crashes on the GPU | Sign-in window runs without GPU |
| `ncryptshim` | Crash on start and on save (signature check) | Own `ncrypt.dll` for Revit |
| `wbemshim` | Crash on New Project and in Options (system info query) | Own WMI wrapper |
| `richedit` | Text in views and dialogs fails | Microsoft RichEdit DLLs for Revit |
| `tlbpin` | Creating views with text is 2× slower | Cache for a type library |
| `d3d9dxvk` | UI and Dynamo windows hang | DXVK for Direct3D 9 |
| `warpshim` | Materials dialog does not open | Software D3D11 device → normal device |
| `dynamo` | Dynamo crashes on 3D preview | 3D background preview off |
| `pdfprinter` | No printers in the bottle | "Revit PDF" printer → `~/Documents/Revit-PDF` |

## Speed

RFO Benchmark (Full_Simplified, average of 3 runs) on an Apple M5 Mac, 16 GB: modeling 121.3 s, graphics 24.9 s.
A 2020 Windows laptop (Intel i7-10750H, 16 GB) scored 193.3 s and 43.9 s. Caveat: that Windows run was older and
done over remote desktop, which lowers its graphics score.
