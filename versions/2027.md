# Revit 2027

**Status: ⚠️ mostly works.** Tested by hand on the basics: sign-in, a new project, walls and modeling.
Web-based panels work. When a new web window opens, the others sometimes redraw. Many everyday features are not tested yet.

## What works / what doesn't

- ✅ Install, sign-in (through your Mac's browser), new project (Metric), walls, modeling.
- ✅ Project templates are found.
- ✅ Start screen (all tabs), Project Browser, web panels, Manage Links, Collaborate → Issues. No browser crashes seen in a session.
- ⚠️ When a new web window opens, other web windows sometimes redraw. Nothing is lost.
- ⚠️ The installer ships only about 48 families. Revit 2027 probably loads families online (not confirmed).
- Not tested yet: text, 3D, Materials, saving, printing, add-ins.

## Requirements

- Installer from your Autodesk Account, both files in `installers/revit2027/` (or only `Create_Installer_RVT_2027_…_WIN64.exe`:
  the install downloads both files from it):
  `RVT_2027_NA_win_db_001_002.exe` (30 MB) and `RVT_2027_NA_win_db_002_002.7z` (10 GB). Tested build: 27.0.4.412.
- Extra files: `installers/redist/win7sp1/x64/msls31.dll`. Recommended: a current WebView2 runtime in
  `installers/redist/webview2/`. See [installers/README.md](../installers/README.md).
- `brew install sevenzip winetricks cabextract ghostscript python3`
- Disk: about 10 GB for the installer and 11 GB for the unpacked files, plus the bottle.

## Install

```bash
./install.sh 2027
```

This unpacks the installer, creates the bottle `rvt2027-a`, installs Revit and all fixes, registers the sign-in
link handler and puts a Revit 2027 app in `~/Applications`.

Add-ins: the add-in script is not set up for 2027 yet.

## First launch

Revit opens the Autodesk sign-in page in your Mac's web browser. After you sign in, the browser asks which app should
open the link. Choose **Autodesk Sign-In (rvt2027-a)**.

## Workarounds

Same steps as [Revit 2026](2026.md), applied as they are. Only some were checked one by one on 2027.

| Step | What breaks | What we do |
|---|---|---|
| `rvt`, `pkgs`, `asc` | Autodesk installer (ODIS) | Install the MSI and packages directly |
| `licensing`, `svcshim` | Licensing service does not start as a Windows service (checked) | Small wrapper service runs it |
| `revitini` | "Default family templates is empty or invalid", no templates (checked) | Set the language code in `Revit.ini` |
| `rvtfix` | Start screen and Project Browser white, ~60 % CPU (checked) | Browser flags that make it draw |
| `wv2fix` | Browser crashes on clicks and tabs, empty Project Browser (checked) | Own `version.dll` in the browser process |
| `ncryptshim`, `richedit`, `tlbpin`, `dpipatch`, `warpshim`, `d3d9dxvk`, `webview2`, `gdoff` | Same as 2026 (not checked separately) | Same as 2026 |
