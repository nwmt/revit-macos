# Revit 2026

**Status: ⚠️ mostly works.** Tested by hand. The core modeling workflow works. Web-based panels (start screen,
Manage Links) work but sometimes redraw, and their browser process rarely crashes and restarts itself.
Generative Design is turned off.

## What works / what doesn't

- ✅ Sign-in (through your Mac's browser), new project, walls, modeling, text, 3D, Materials, saving.
- ✅ Add-ins: pyRevit 7.0.0 and RevitLookup 2026.1.4 load and their windows open.
- ✅ The RFO Benchmark runs to the end.
- ⚠️ Start screen and Manage Links (built-in web browser): work, but sometimes redraw; rare browser crashes, restarted automatically.
- ⚠️ With add-ins installed, the `wpfsw` step is required, or black rectangles appear across Revit. The add-in script does it for you.
- ❌ Generative Design: fails to load, so we turn it off.
- Not tested yet: printing to PDF, Dynamo, exports, worksharing, long sessions.

## Requirements

- Installer from your Autodesk Account, both files in `installers/revit2026/`:
  `RVT_2026_NA_win_db_001_002.exe` (16 MB) and `RVT_2026_NA_win_db_002_002.7z` (9.8 GB). Tested build: 26.0.4.409.
- Extra files: `installers/redist/win7sp1/x64/msls31.dll`. Recommended: a current WebView2 runtime in
  `installers/redist/webview2/`. See [installers/README.md](../installers/README.md).
- `brew install sevenzip winetricks cabextract ghostscript python3`
- Disk: about 10 GB for the installer, 11 GB for the unpacked files, about 7 GB for the bottle.

## Install

```bash
./install.sh 2026
```

This unpacks the installer, creates the bottle `rvt2026-a`, installs Revit and all fixes, registers the sign-in
link handler and puts a Revit 2026 app in `~/Applications`.

Optional add-ins (RevitLookup 2026.1.4 + pyRevit 7.0.0, plus the `wpfsw` fix):

```bash
REVIT_YEAR=2026 ./scripts/d8-addins.sh rvt2026-a
```

## First launch

Revit opens the Autodesk sign-in page in your Mac's web browser. After you sign in, the browser asks which app should
open the link. Choose **Autodesk Sign-In (rvt2026-a)**.

## Workarounds

The install applies all of these. Step names match `scripts/install-odis.sh`.

| Step | What breaks | What we do |
|---|---|---|
| `rvt`, `pkgs`, `asc` | Autodesk installer (ODIS) | Install the MSI and packages directly |
| `licensing`, `svcshim` | Licensing service does not start as a Windows service | Small wrapper service runs it |
| `ncryptshim` | Crash on start (signature check) | Own `ncrypt.dll` for Revit |
| `richedit`, `tlbpin` | Crash on text when creating a project | Microsoft RichEdit DLLs + type library cache |
| `dpipatch` | Crash when opening a view (missing Windows function) | Patch one import in a copy of the DLL |
| `warpshim` | Materials dialog does not open | Software D3D11 device → normal device |
| `d3d9dxvk` | Direct3D 9 panels unreliable | DXVK for Direct3D 9 |
| `webview2` | Built-in web pages fail (old browser runtime) | Install a current WebView2 runtime |
| `rvtfix` | Start screen white, browser uses ~60 % CPU, viewport slow | Browser flags that make it draw |
| `wv2fix` | Browser crashes on clicks and resizes | Own `version.dll` in the browser process |
| `gdoff` | Generative Design error on start | Turn the add-in off |
| `wpfsw` (add-ins) | Black rectangles after add-ins load | WPF draws in software |

## Speed

RFO Benchmark (Full_Simplified, average of 3 runs) on an Apple M5 Mac, 16 GB: modeling 128.0 s, graphics 32.4 s.
Caveat: there is no Windows reference for 2026, and other apps were using a lot of CPU during the run.
It uses a newer benchmark set than 2020, so compare the two only roughly.
